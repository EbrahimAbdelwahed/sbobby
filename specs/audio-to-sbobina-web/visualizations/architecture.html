Implementation roadmap · 2026-09-01

Local content, ephemeral compute, explicit provider transit.

The browser owns every durable lesson artifact. Vercel authenticates and forwards bounded requests; Upstash stores only redacted expiring quota counters. Groq receives transient audio chunks; DeepSeek receives transient text. No hidden lesson store connects the planes.

Ownership planes

Browser data plane

Owns the project

  • Ephemeral source file and audio worker
  • IndexedDB text, receipts, and pipeline state
  • Transcript assembly and literal index
  • Full/study document model
  • PDF rendering and export/import
Vercel control plane

Never owns a lesson

  • Clerk session and invite authorization
  • Request budgets and schemas
  • Groq and DeepSeek adapters
  • Redacted metrics and TTL quota counters
  • Cache-Control: no-store
Provider plane

Processes transient input

  • Groq: independent audio chunk
  • DeepSeek: one typed text operation
  • No model fallback
  • No semantic quality claim

Decision gates

Gate A

Audio feasibility

Fail if realistic M4A/MP3 cannot become independently decodable chunks below the Vercel budget without persistent storage.

Gate B

Structural completeness

Fail if segmentation misses transcript units, DeepSeek cannot satisfy the schema after one same-model repair, or a PDF omits content.

Gate C

Privacy evidence

Fail if audio or lesson content appears in server storage, cache, analytics, tracing, logs, public errors, or a client bundle secret.

Explicit consequence:

Closing the tab pauses work. A new device has no projects. Sharing is an exported file. These are product contracts, not implementation gaps.
