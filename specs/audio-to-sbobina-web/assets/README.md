# Feature assets

No copyrighted or user recordings are part of this specification.

Slice 00 must generate deterministic synthetic 90-minute M4A and MP3 fixtures
under this directory or a test-fixture subdirectory, record their hashes and
encoding parameters, and keep them out of Git if their size is impractical.
The committed replacement contract is a small manifest plus a reproducible
fixture-generation command.

Future visual references, approved screenshots, PDF page renders, and comparison
contact sheets become feature-owned evidence and must be copied here rather than
left only in mutable test-output folders.
